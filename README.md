# Questionnaire-Platform-for-Soundscapes-
目前在城市声环境研究中，在线收集居民对不同声源的主观评价仍缺乏成熟的网页设计工具。大多数研究依赖线下问卷或实验室测试，数据收集效率低、样本量有限，难以满足大规模与多场景的研究需求。同时，线下调查在时间与空间上存在限制，无法实现便捷的推广与快速反馈。 本软件旨在为声环境研究提供一个高效的在线问卷平台。通过网页端即可播放15类典型城市声源音频，记录参与者的主观评价与人口学信息，并保存相应时间戳。用户无需安装额外软件，只需通过浏览器即可完成测试，提交结果自动上传至服务器，便于后续整理与导出。 与传统的调查方式相比，本软件具有操作简便、样本获取便捷、数据存储安全和可复现性强等优点。其轻量化的设计不仅降低了研究的实施成本，也为声环境舒适度评价和居民出行选择研究提供了可扩展的技术支撑。
